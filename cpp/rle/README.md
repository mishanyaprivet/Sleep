# RLE-кодування рядка (C++17)

Навчальна програма, що стискає рядок методом RLE: кожна послідовність
однакових символів замінюється на символ і кількість повторень.

| Вхід           | Вихід       |
|----------------|-------------|
| `"aaaaaa"`     | `"a6"`      |
| `"aaabccdddd"` | `"a3b1c2d4"`|
| `""`           | `""`        |

Функція `rle(const std::string& s, size_t i = 0, int count = 1)` рекурсивна,
без циклів.

## Збірка та запуск

```sh
g++ -std=c++17 -Wall -Wextra -o rle rle.cpp
./rle
```

Програма спершу проганяє тести через `assert` і виводить
«Усі тести пройдено!», а потім просить ввести рядок і друкує результат.

> Примітка: глибина рекурсії дорівнює довжині рядка, тож для дуже довгих
> рядків (сотні тисяч символів) можливе переповнення стека.
